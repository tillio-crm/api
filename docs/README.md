# Dokumentacja SDK

Katalog `examples/` zawiera krótkie, kompletne przykłady użycia każdego zasobu
SDK - gotowe do wklejenia fragmenty PHP z komentarzami o pułapkach danego
endpointu. Opis konfiguracji klienta, trybów pracy, błędów i limitów znajduje
się w [głównym README](../README.md).
